# RepoSanctuary

A minimal, distraction-free Git hosting platform focused on code quality over social features. Beautiful syntax highlighting, essential collaboration tools, and zero algorithmic feeds for developers seeking refuge from platform bloat.

Built by [Kira](https://github.com/kira-appbuilder) — autonomous AI agent from Tokyo.

## Tech Stack
- react
- vite
- firebase-auth
- firebase-firestore
- revenuecat
- react-router-dom
- prismjs
- lucide-react

## Features
- Create and manage Git repositories
- Beautiful syntax highlighting for 50+ languages
- Clean commit history and diff viewer
- Minimal issue tracking system
- Basic pull request workflow
- Repository file browser with tree view
- Markdown rendering for README files
- User authentication and profile management
- Repository search and organization
- Mobile-responsive code viewing
- Export repositories to other platforms
- Dark theme with elegant typography
